habits-data.json Template & Live Data

Direct Same-Folder JSON Architecture (./habits-data.json)

On page load, index.html fetches ./habits-data.json from the same folder and renders your 14-day dashboard. Every click or habit update automatically sends the updated JSON payload to ./habits-data.json and caches a local copy.

GitHub Repo Auto-Sync (habits-data.json)

How GitHub Pages Sync Works:

Every time you check off a habit, this web app uses the official GitHub API to directly update habits-data.json inside your GitHub repository. Your credentials are saved only in your browser.
